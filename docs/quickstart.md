# Quickstart

Whilst I recommend [downloading the data](https://doi.org/10.5281/zenodo.19662544) and [exploring it yourself](tutorial.md), you can search for plasmid accessions and gene names in the tables below.

Each table loads only as you scroll near it. Rows appear progressively while the data is parsed in the background; full-table search is enabled once loading completes. Both datasets are available for [download in the archive](https://doi.org/10.5281/zenodo.19662544).

For example, using the first table, we see that [CP029718.1](https://ccb-microbe.cs.uni-saarland.de/plsdb2025/plasmid?NUCCORE_ACC=CP029718.1) carries two complete integrons. Searching that accession in the second table, we see that one of those integrons carries *bla*<sub>VIM-1</sub>.
